# Loader

A loader should be used when loading content on a page asynchronously, such as waiting for search results to load.

## Bar loader

If the user has enabled the 'Reduce motion' setting in their operating system, the [crest loader](#crest-loader) will show instead.

## Crest loader

While this loader can be used on its own, it is also the loader that will be shown if the user has enabled the 'Reduce motion' setting in their operating system.
