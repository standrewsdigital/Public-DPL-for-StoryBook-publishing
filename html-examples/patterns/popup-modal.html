Popup modal

To set up a modal the href and the dialog's data-link attribute must be the same. The href must start with #open-modal e.g. #open-modal, #open-modal-register-interest-form. The modal can be closed via:

  • The 'Close' button
  • Pressing 'Escape'
  • Clicking outside the modal
