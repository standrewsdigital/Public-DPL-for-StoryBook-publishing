Effect utility classes

Use these utility classes to apply consistent shadows and hover treatments across cards, boxes, panels and other reusable content containers.

Drop shadow

Add drop-shadow to apply the standard DPL card shadow without adding hover behaviour.

Standard shadow

This box uses the reusable drop shadow utility.

drop-shadow

Reusable on any box

The class can be added to cards, panels, tiles or other containers.

drop-shadow

No interaction

This keeps the surface static while still giving it depth.

drop-shadow

Primary hover

Combine drop-shadow with hover-primary for the standard blue hover ring and lift effect.

Primary hover effect

This uses the standard DPL blue hover treatment.

drop-shadow hover-primary

For default interactive cards

Use this when a card links to more information or acts as a featured item.

drop-shadow hover-primary

Colour hover variants

Use colour-specific hover classes when a component needs to match a theme, subject area, category or campaign colour.

Green hover

Useful for cards with a green tag or theme.

drop-shadow hover-green

Burgundy hover

Useful for cards with a burgundy tag or theme.

drop-shadow hover-burgundy

Purple hover

Useful for cards with a purple tag or theme.

drop-shadow hover-purple
